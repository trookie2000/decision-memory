## 评测口径

原始附件含人工标注，部分知识跨阶段组织。参考集应由评审者按当前阶段材料建立，再使用 `review init` 和 `review score` 填写判断与汇总结果。

本地 `precision_reviewed`、`recall` 和 `citation_support_reviewed` 为明确标注的自测指标。正式比赛的语义匹配、条目粒度与计分规则仍需以出题方说明为准。
