## 定点修订理由和边界的配对对照

候选从同一份已验收答卷出发，增加一次模型调用，逐条检查理由和边界。程序只接受固定字段的来源替换，或把答卷和权威原文中的完整短语补入理由或边界。新增短语保留逐段原文、主来源、同主题关系及字面值证明。无效修改按字段退回，结论文字、条目身份和未决事项沿用原答卷。11 项离线回归覆盖原文边界、提议状态、真实来源、单位、冲突编辑、旧引文元数据及审计重放。
