# 来源编号审计 v2 验收记录

本轮结论：v2 保留为主动开启的实验功能，默认 `verified` 不变。它尚未达到真实结果发布、完整引用及成本门槛，不能据此宣称 CLI 整体效果提升或获得比赛成绩。

## 实现与验证范围

模型选来源编号，程序填写原文；复核前提供逐字段来源线索，限制跨字段借用实现符号。唯一句片、理由未知、角色准入、历史更新和候选覆盖继续由原有协议校验。新结果使用 schema 4，可离线重建证明。

新增本地 HTTP 回归覆盖两次正常请求、四请求上限、错误编号、字段符号、待复核保留、断流、认证回显及结果篡改。独立代码评审发现的版本降级、符号子串误匹配及大写开头符号漏检均已用失败测试复现并修复。

真实模型试验冻结在 `b2ab61f`。随后发现完整绝对 API 路径可能因前导斜线被丢弃而误拒绝，已在 `6c7fa08` 修复。最终源码的 297 项自动测试通过；该修复未重发模型请求，下面的模型结果仍属于原冻结版本。

## 材料与判卷

一个已用于修复的开发需求、两个本轮实现前隔离准备的保留需求。两个保留需求含 13 条固定参考、41 处逐字依据，预测前经独立核对。参考仍为暂定，人工核准待完成。保留材料未包含明确未知或仅 Agent 提议的参考检查点，相关能力还需结合开发例和合成回归判断。

预测只读取原对话与产物。每个案例由独立上下文判卷，禁止读取方法映射、成本、其他案例及旧评分。所有原响应、旧评分和固定参考保持原样。原材料、运行副本、匿名判卷及映射仅存于本机忽略目录，不进入公开源码包。

内容正确、全部字段引文支持、严格参考覆盖分别计数。严格引用要求结论、理由、边界各自的实际引文支持全部文字；逐字存在和编号合法仍不足以证明语义。参考覆盖只接受正确且全部字段引文受支持的链接。额外有效知识可判正确，不要求必须出现在固定参考中。

总输入 393,511、输出 82,034 token，整轮约 25.9 分钟，峰值并发 2。未配置单价，金额保持未知。H02 的 v2 输出约为对照 3.4 倍，且没有正式结果；这不满足成本门槛。

预设上限为 5 个任务、20 次请求；已知输入达到 500,000 或输出达到 70,000 token 时停止启动新任务，在途请求可完成。输出启动阈值触发时，五个任务均已启动，最后一个请求仍在途，因此最终输出超过 70,000。没有在触发后新增任务或换目录重发。

## 发布取舍与复现

保留默认 verified；需要研究来源审计时显式传 `--evidence-audit v2`。优先改进编号错误定位、字段证据绑定和审计回复体积，再用新的有限对照验证可用性、质量与成本。任何后续改动均保留这轮失败结果，不用离线派生结果替换真实发布率。

本机完整记录位于 `runs/semantic-grounding-eval-20261117/`。`experiment.json` 固定代码、配置、材料及预算；`matrix-state.json` 和逐任务 `receipt.json` 保存调用；`grading/` 保存匿名原始判断；`final-summary.json` 汇总；`verification.json` 的 48 项核验均通过。公开仓库只包含实现、合成测试和这份汇总。
